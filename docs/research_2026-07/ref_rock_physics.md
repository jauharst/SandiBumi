## Methods
### Fluid properties - Batzle-Wang (brine / oil / gas)
Compute density, velocity, slowness, bulk modulus, compressibility of each pore fluid at reservoir T-P. the reference suite implements Batzle & Wang (1992) in a compiled library; wrappers + I/O fully specced from brine/oil/gas.lls and tp_rock_fluid_property.info. Equations must come from the published paper / Rock Physics Handbook ch.6 (standard, uncontroversial).

Equations:
T in degC, P in MPa, S = salinity weight fraction (ppm/1e6), G = gas specific gravity, Rg = GOR (L/L), API = 141.5/rho0 - 131.5. PURE WATER: rho_w = 1 + 1e-6(-80T - 3.3T^2 + 0.00175T^3 + 489P - 2TP + 0.016T^2 P - 1.3e-5 T^3 P - 0.333P^2 - 0.002TP^2); Vp_w = SUM_{i=0..4,j=0..3} w_ij T^i P^j (Batzle-Wang Table 1 coefficients). BRINE: rho_B = rho_w + S(0.668 + 0.44S + 1e-6[300P - 2400PS + T(80 + 3T - 3300S - 13P + 47PS)]); V_B = Vp_w + S(1170 - 9.6T + 0.055T^2 - 8.5e-5T^3 + 2.6P - 0.0029TP - 0.0476P^2) + S^1.5(780 - 10P + 0.16P^2) - 1820S^2; K_B = rho_B * V_B^2. Gas-saturated brine: log10(GWR_max)=log10(0.712 P |T-76.71|^1.5 + 3676 P^0.64) - 4 - 7.786 S(T+17.78)^-0.306, use GAS_INDEX*GWR_max; dissolved gas lowers K per B-W eq.  GAS: Tpr=(T+273.15)/(94.72+170.75G), Ppr=P/(4.892-0.4048G); E=0.109(3.85-Tpr)^2 exp{-[0.45+8(0.56-1/Tpr)^2] Ppr^1.2/Tpr}; Z=[0.03+0.00527(3.5-Tpr)^3]Ppr + 0.642Tpr - 0.007Tpr^4 - 0.52 + E; rho_G = 28.8 G P/(Z R (T+273.15)); gamma0 = 0.85 + 5.6/(Ppr+2) + 27.1/(Ppr+3.5)^2 - 8.7exp[-0.65(Ppr+1)]; K_G ~ P*gamma0/(1 - Ppr/Z * dZ/dPpr).  OIL (live): B0 = 0.972 + 0.00038[2.4 Rg (G/rho0)^0.5 + T + 17.8]^1.175; pseudo-density rho' = (rho0/B0)/(1+0.001Rg); true density rho_G-corrected rho_oil = (rho0 + 0.0012 G Rg)/B0 then pressure/temperature terms; V_oil = 2096(rho'/(2.6-rho'))^0.5 - 3.7T + 4.64P + 0.0115[4.12(1.08/rho' - 1)^0.5 - 1]TP; K_oil = rho_oil V_oil^2. Bubble point: invert Standing-type Rg(P_bp) to estimate GOR when missing (the reference suite: GOR_EST from P_bp; LIMIT_GOR caps GOR so P_bp <= P_form). Salinity from Rw: Bateman-Konen SALW = 10^((3.562 - log10(Rw75F - 0.0123))/0.955), Kennedy 5th-order rational fit for 39161-275000 ppm (coefficients in ricec.lls source).

Inputs: Per-frame: formation T (log or gradient TEMP_surf + TVD*TGRAD, or water-bottom origin: zmudline = TVD - (elev_ref + water_depth)), formation P (log or PGRAD_SEAW*water_depth + zmudline*PGRAD_FM). Brine: salinity ppm (or RT/CT + m + rho_ma -> Rw -> salinity), GAS_INDEX 0-1. Oil: API or rho_std g/cc, GOR scf/bbl, gas gravity G, LIMIT_GOR flag. Gas: specific gravity G (0.56-1.8).
Outputs: Per fluid: RHO_FL_x (g/cc), VEL_FL_x, DT_FL_x, KMOD_FL_x (GPa), COMP_FL_x; plus GWR_EST, SALW_CALC, GOR_EST, PRESS_BP, MU_OIL (cP).
Calibration: Match against PVT reports where available (Mahakam: gas-condensate GOR/API from well tests). QC crossplot: computed brine DT vs measured DT in known wet clean sands. the reference suite's Parameter Sensitivity script loops GOR x API grid (e.g. GOR 700-750 step 50, API 50-60 step 10) and stores each result annotated ACI_oXX_gYYYY - replicate as a sensitivity table.

### Fluid mixing (Reuss / Voigt-patchy / Brie)
Effective modulus + density of brine+hydrocarbon pore-fluid mix; feeds Kfl into Gassmann. Verbatim from fluid_mix.lls.

Equations:
UNIFORM (Reuss, fine-scale): 1/Kfl = Sw/Kw + So/Ko + Sg/Kg. PATCHY (Voigt): Kfl = Sw*Kw + So*Ko + Sg*Kg. BRIE (1995 SPE-30595): rescale liquid sats sat_b'=Sb/(Sb+So), sat_o'=So/(Sb+So); Kliq = 1/(sat_b'/Kb + sat_o'/Ko) (Reuss); Kfl = (Kliq - Kg)*(1-Sg)^e + Kg, e default 3 (range 1-40; 1~patchy, 40~uniform, field data 2-5; uses liquid saturation (1-Sg), conceptually Sxo since oil/water acoustically similar). Density always arithmetic: rho_fl = sum(Si*rhoi).

Inputs: Per-fluid KMOD/RHO (or DT or VEL - accept slowness OR velocity OR modulus, normalize internally, an idiom worth copying), SAT_GAS, SAT_OIL (brine = 1-So-Sg), MIX_MODEL, E_CONST.
Outputs: KMOD_FL (GPa), RHO_FL, DT_FL, VEL_FL.
Calibration: Choice of law is the main lever for gas sands: Brie e tuned until modeled DT matches measured DT in known gas zones.

### Solid mineral mixture moduli (Voigt-Reuss-Hill from mineralogy)
K0, mu0, rho0 of the grain mix from mineral volume fractions - the Gassmann K0 input. Direct consumer of multimin/SSC volume outputs. Specced from tp_rock_solid_mix_model.info.

Equations:
Per mineral i: Ki = rhoi(Vpi^2 - 4Vsi^2/3), mui = rhoi*Vsi^2 (from mineral DT/DTS/rho defaults or user values). Voigt: M_V = SUM fi*Mi. Reuss: 1/M_R = SUM fi/Mi. VRH: M_VRH = (M_V + M_R)/2 for both K and mu. rho_min = SUM fi*rhoi. Volumes normalized to SUM fi = 1 if they don't. Back out DT_MIN/DTSM_MIN/POIS_MIN from VRH moduli.

Inputs: Volume fraction logs for up to ~31 predefined + user minerals; per-mineral Vp/Vs/rho (defaults: quartz 6048/4118/2650, calcite 6378/3435/2710, dolomite 7008/3932/2847, anhydrite 6098/3356/2977, orthoclase 5698/3310/2570, albite 5531/3121/2610, siderite 6959/3591/3960, halite 4550/2627/2037, muscovite 6220/2045/2840, biotite 6169/1359/3220, illite/kaolinite/chlorite/smectite, wet clay/shale slots, silt, pyrite, coal (anthracite/lignite), kerogen, 2 spare).
Outputs: KMOD_MIN, UMOD_MIN (GPa, VRH + separate Voigt and Reuss bound logs), RHO_MIN, DT_MIN, DTSM_MIN, VELC/VELS_MIN, POIS_MIN.
Calibration: In 100% single-mineral intervals modeled DT_MIN should approach matrix DT (55.5 us/ft quartz). Wet-clay slots are the tuning knobs: clay moduli are the most uncertain - calibrate against measured DT/DTS in shales (Vsh~1).

### Gassmann fluid substitution (clean-sand + Vsh shaly-sand variants)
Core module. Two modes mirroring the reference suite: (A) tp_gassmann_new clean-sand - full log-driven; (B) gassmann_vsh - clean-sand endpoint substitution pro-rated with hard shale by Vsh. Full source equations available.

Equations:
Forward Gassmann (mod_sat.lls): a = Kdry/(K0-Kdry); b = Kfl/(phi(K0-Kfl)); c = a+b; Ksat = K0*c/(1+c); mu_sat = mu_dry. Inverse (dry frame from measured saturated, gassmann_vsh.lls GASSMANN subroutine): Ksat_insitu = rho*Vp^2 - 4mu/3, mu = rho*Vs^2; a = phi*K0/Kfl_init + 1 - phi; b = phi*K0/Kfl_init + Ksat/K0 - 1 - phi; Kdry = (a*Ksat - K0)/b. Re-saturate with final fluid: term1 = Kdry + 4mu/3; term2 = (1-Kdry/K0)^2; term3 = (1-phi-Kdry/K0)/K0 + phi/Kfl_final; Vp_new = sqrt((term1 + term2/term3)/rho_new); rho_new = (1-phi)rho0 + phi*rho_fl_final; Vs_new = Vs*sqrt(rho_old/rho_new) (shear modulus constant, density effect only). If DTS missing: get Vs from Poisson via Vs = Vp*sqrt((0.5-nu)/(1-nu)), nu limited 0.1-0.5. K0 from clean-sand matrix: K0 = rho_ma(Vp_ma^2 - 4Vs_ma^2/3). Vsh proration (shaly variant): DT_subs = dtf(1-Vsh) + Vsh*DT_hard_shale; RHOB_subs = rhobf(1-Vsh) + Vsh*RHOB_hsh; only substitute where Vsh < VSH_CUTOFF (default 0.7) and phi >= POR_MIN. Failure detection: term4<0 => no Gassmann solution.

Inputs: DT, DTSM (or POIS), RHOB, PHI (or phi from density: phi=(rho_ma - rhob_clsd)/(rho_ma - rho_fl)), VSH, initial sats (Soi,Sgi - do NOT assume 100% brine), final sats (only ONE hydrocarbon allowed, capped at 1-SW_IRR, SW_IRR default 0.15), fluid triplets (K,rho per brine/oil/gas from Batzle-Wang module), mineral K0/rho0 (from VRH module or clean-sand matrix constants: quartz rho 2.65, DTp 55.5, DTs 88 us/ft, Kb 37.5 GPa), MIX_MODEL, substitution trigger (lithology interval match OR cutoffs Vsh<0.2 & phi>0.05), VSH_CUTOFF, hard-shale DT/RHOB end members.
Outputs: KMOD_DRY, UMOD_DRY, KMOD_SUBS, UMOD_SUBS, DT_SUBS, DTSM_SUBS, VELC_SUBS, VELS_SUBS, RHOB_SUBS, POIS_SUBS, VPVS_SUBS, POR_SUBS (doubles as status flag: missing=not attempted, phi=done, -0.1 missing inputs, -0.2 missing fluids, -0.3 no solution, -0.4 Vsh>cutoff), LNRV before/after, FLAG_SUBS string log (BLACK/OIL/GAS/WET). Summary report with frame counts per outcome.
Calibration: Clean-sand endpoint values (DT_CLSD, DTSM_CLSD, RHOB_CLSD at 100% Sw) picked over a good wet clean-sand zone NEAR the target sand (log-function-of-depth or constants). Sanity: check density-porosity ~ sonic-porosity before trusting the frame. QC = overlay measured DT/DTS/RHOB vs the wet-substituted model in known wet sands (should overlie), then substitute to gas/oil and compare LNRV_IN vs LNRV_SUBS. Track per-frame status flags and report counts.

### Vs prediction (Greenberg-Castagna, mudrock, Han) when DTS missing
7 selectable models per tp_rock_dtsm_from_models.info. GC full multimineral iterative version + quick empirical lines. Mahakam relevance: most older wells lack DTS.

Equations:
GC (per-lithology quadratic on 100% brine Vp, km/s, coefficients a2/a1/a0 from Greenberg-Castagna 1992 - compiled in the reference suite, take from paper): sandstone Vs=0.80416Vp-0.85588; limestone Vs=-0.05508Vp^2+1.01677Vp-1.03049; dolomite Vs=0.58321Vp-0.07775; shale Vs=0.76969Vp-0.86735. Multimineral composite = VRH-style: Vs = 0.5{ SUM_i Xi(SUM_j aij Vp^j) + [SUM_i Xi(SUM_j aij Vp^j)^-1]^-1 }, SUM Xi=1 (normalize). Since measured Vp is at in-situ saturation but GC needs brine Vp: seed Vpp=(1+delta)Vp (delta 0-0.2), iterate Gassmann substitute-to-brine <-> GC until Vp converges (fixed threshold). GC_MODIFIED: Mavko-Chan-Mukerji 1995 P-wave-modulus approximation replaces K with M in Gassmann form (avoids needing Vs during the brine correction), then GC at 100% brine, then mu constant to go back to in-situ Vs. HAN shaly sandstone (water-sat, km/s): clay>25%: Vs=0.842Vp-1.099; clay<25%: Vs=0.754Vp-0.657; por>15%: Vs=0.756Vp-0.662; por<15%: Vs=0.853Vp-1.137. MUDROCK (Castagna 1985): Vs=0.862Vp-1.172. MODULUS: Vs=sqrt(mu/rho). POISSON: Vs=Vp*sqrt((1-2nu)/(2(1-nu))). VPVS: Vs=Vp/VPVS.

Inputs: DT, PHIE, mineral volume fractions + per-mineral Vp/Vs/rho + brine/oil/gas fluid props + Sw/So/Sg + SW_IRR + mix model (GC variants); just DT (Han/mudrock); UMOD+RHOB (modulus); PR or VPVS logs.
Outputs: DTSM_x + VELS_x per model (DTSM_GC, DTSM_MODIFIED, DTSM_HAN, DTSM_MUDROCK, DTSM_UMOD, DTSM_PR, DTSM_VPVS).
Calibration: Calibrate in wells that HAVE measured DTS: overlay predicted vs measured DTSM, pick model + delta + coefficients minimizing residual, then apply to DTS-less wells. This is Jauhar's existing synthetic-log philosophy (memory: docs/workflow_standards.md synthetic logs).

### Vp / DT and RHOB estimation models (pseudo-sonic, pseudo-density)
Gap-filling estimators from dt_from_models.lls + rhob_from_models.lls, all equations source-visible. Useful for log repair before rock physics and for synthetic-log QC.

Equations:
Wyllie: 1/V = phi/Vf + (1-phi)/Vm. Raymer-Hunt-Gardner: phi<0.37: V=(1-phi)^2 Vm + phi Vf; phi>0.47: 1/(rho V^2) = phi/(rho_f Vf^2) + (1-phi)/(rho_m Vm^2); 0.37-0.47: 1/V = (0.47-phi)/(0.1 V37) + (phi-0.37)/(0.1 V47) (V37 from low branch at 0.37, V47 from high branch at 0.47). Gardner: Vp=(rhob/0.23)^(1/0.25) ft/s (constants parameterized GGG_CONSTANT/EXPONENT); inverse rho=0.23V^0.25. Lindseth: V = C1/(1 - C2*rhob) with C1=3460, C2=0.308 (rho=(V-3460)/(0.308V)). Faust: DT = 513.3/(Z*RT)^(1/6) (constant+exponent parameterized; uses CT=1000/RT first if present). Moduli: Vp=sqrt((K+4mu/3)/rho). Hilterman density: rho_sand = -4.05+1.61 log10(V_sand); rho_shale = -0.81+0.759 log10(V_shale); rho = (1-Vsh)rho_sand + Vsh rho_shale (NOTE the reference suite source has sand/shale velocities swapped in these two lines - fix in SandiBumi). Porosity density: rho=(1-phi)rho_min+phi rho_fl.

Inputs: Model selector + PHIE, DT_MIN/DT_FL or velocities, RHOB, RT/CT+DEPTH (Faust), TWT, K/U moduli, Vsh.
Outputs: DT_x + VELC_x per model (DT_WYLLIE, DT_RAYMER, DT_GGG, DT_LINDSETH, DT_FAUST, DT_TWT, DT_MODULI, DT_PR, DT_VPVS); RHOB_POR/GGG/LINDSETH/HILTERMAN.
Calibration: Regress GGG/Lindseth/Faust constants per field against measured pairs; QC overlay predicted vs measured in logged intervals.

### Elastic attributes for crossplots (AI, SI, VpVs, Poisson, LambdaRho-MuRho)
Frame-by-frame attribute computation from calc_pois_vpvs.lls (source-visible verbatim). Feeds SandiBumi crossplot views (AI vs VpVs, LR vs MR).

Equations:
vpvs = DTS/DTC. nu = (0.5 vpvs^2 - 1)/(vpvs^2 - 1), limit 0-0.5, missing if vpvs==1. With rho g/cc, V km/s (moduli in GPa): MMOD = rho Vp^2 (P-wave modulus); UMOD = rho Vs^2; KMOD = rho(Vp^2 - 4Vs^2/3); YMOD = 2(1+nu)UMOD. ACI_C = rho*Vp (SI units kg/m2s), ACI_S = rho*Vs. LAMBDA_RHO = ACI_C^2 - 2 ACI_S^2; MU_RHO = ACI_S^2; LMR_RATIO = LR/MR. Inverse: VPVS = sqrt(2(1-nu)/(1-2nu)) (sentinel 9999 at nu=0.5). Accept SONIC or VELOCITY input mode with reciprocal cross-conversion of all outputs.

Inputs: DT+DTSM (US/M) or VELC+VELS (KM/S), RHOB (K/M3).
Outputs: POIS, VPVS, KMOD/MMOD/UMOD/YMOD (GPa), DT/DTSM/VELC/VELS cross-converted, ACI_C, ACI_S, LAMBDA_RHO, MU_RHO, LMR_RATIO.
Calibration: None (deterministic transform). Known the reference suite bug to avoid: pois_from_vpvs.lls clamps the INPUT pois not the computed output - copy calc_pois_vpvs.lls behavior instead. Guard vpvs==1 and nu==0.5 singularities explicitly.

### Bounds: Voigt-Reuss-Hill and Hashin-Shtrikman (multiphase)
Upper/lower moduli bounds for grain+pore mixtures, N<=8 solids + 1 fluid, with porosity-sweep mode for template curves on crossplots. Manifest gives I/O; HS formulas from RPH/Berryman (standard).

Equations:
Voigt: M_V = SUM fi Mi; Reuss: 1/M_R = SUM fi/Mi; VRH = mean. HS 2-phase (Mavko RPH): K^HS+/- = K1 + f2/[(K2-K1)^-1 + f1(K1 + 4mu1/3)^-1]; mu^HS+/- = mu1 + f2/[(mu2-mu1)^-1 + 2f1(K1+2mu1)/(5mu1(K1+4mu1/3))]; upper bound when subscript 1 = stiffest phase, lower when softest. Multiphase (Berryman 1995): K^HS+ = Lambda(mu_max), K^HS- = Lambda(mu_min) with Lambda(z) = [SUM fi/(Ki + 4z/3)]^-1 - 4z/3; mu^HS+ = Gamma(zeta(K_max,mu_max)), mu^HS- = Gamma(zeta(K_min,mu_min)), Gamma(z) = [SUM fi/(mui + z)]^-1 - z, zeta = mu/6 (9K+8mu)/(K+2mu). With fluid phase mu=0 => HS- shear = 0 (suspension). Velocities from bound moduli + rho = SUM fi rhoi + phi rho_fl.

Inputs: Per phase KMOD/UMOD/RHO/VOL (up to 8 solids, volumes normalized), KMOD_FL/RHO_FL, PHIE (or PHIE_INC sweep 0-1).
Outputs: K/U for Reuss, Voigt, VRH (or HS lower/upper/avg) + DT/DTSM/VELC/VELS per bound + RHOB_SAT + PHIE_SEQ.
Calibration: Not calibrated - used as QC envelopes: measured data plotted on K-phi / Vp-phi crossplot must fall inside bounds; distance from HS+ indicates diagenesis/cementation (Avseth rock physics diagnostics).

### Krief and Critical-Porosity (Nur) moduli-porosity models
Empirical dry/saturated moduli vs porosity, full source in mod_krief.lls. Sweep mode produces model lines for velocity-porosity crossplots.

Equations:
KRIEF: beta (Biot coeff) = 1 - (1-phi)^(3/(1-phi)); Kdry = K0(1-beta); mu_dry = mu0(1-beta); M = 1/[(beta-phi)/K0 + phi/Kf]; Ksat = Kdry + M*beta^2; mu_sat = mu_dry. When 1-beta < 1e-6 -> suspension: Kdry=mu=0, Ksat = Reuss[(1-phi)/K0 + phi/Kf]^-1. CRITICAL POROSITY (phi < phi_c, default 0.36): Kdry = K0(1 - phi/phi_c); mu_dry = mu0(1 - phi/phi_c); Kc = Reuss at phi_c = 1/[phi_c/Kf + (1-phi_c)/K0]; Ksat = Kdry + phi*Kc/phi_c; mu_sat = mu_dry. phi >= phi_c -> suspension (Reuss, mu=0). Both: rho_sat = rho0(1-phi) + rho_fl*phi; Vp = sqrt((Ksat + 4mu_sat/3)/rho); Vs = sqrt(mu_sat/rho); at phi=0, sat = dry = mineral.

Inputs: KMOD_MIN/UMOD_MIN/RHO_MIN (from VRH module), KMOD_FL/RHO_FL (from fluid module), PHIE (Krief wants PHIT), PHIE_C, SEQUENCE_RUN + PHIE_INC.
Outputs: KMOD_DRY, UMOD_DRY, KMOD_SAT, UMOD_SAT, DT_SAT, DTSM_SAT, VELC_SAT, VELS_SAT, RHOB_SAT, PHIE_SEQ.
Calibration: phi_c is the tuning parameter (0.36 sphere pack; 0.40 typical sands). Fit model line through measured Vp-phi cloud in wet sands; QC modeled vs measured DT overlay.

### Contact models: Hertz-Mindlin, soft/stiff sand (modified Hashin-Shtrikman), cemented sand
Granular-medium dry-frame models then Gassmann-saturated; tp_rock_contact_model.info gives modes/IO, formulas from Dvorkin-Nur 1996 / Mavko RPH (standard).

Equations:
HERTZ-MINDLIN at critical porosity: K_HM = [ n^2 (1-phi_c)^2 mu0^2 P_eff / (18 pi^2 (1-nu0)^2) ]^(1/3); mu_HM = (5-4nu0)/(5(2-nu0)) [ 3 n^2 (1-phi_c)^2 mu0^2 P_eff / (2 pi^2 (1-nu0)^2) ]^(1/3); nu0 from mineral moduli; P_eff = effective overburden (from obpress_eff: S - Pp). Coordination number n: constant (default 9) or Murphy 1982 n = 20 - 34phi + 14phi^2 (the reference suite: MURPHY/GARCIA_MEDINA phi<=0.384/MAKSE phi<=0.37 correlations - only Murphy is well published; mark others the reference suite-specific). SOFT SAND (modified HS lower, Dvorkin-Nur): for phi<phi_c interpolate HM endpoint to mineral: Kdry = [ (phi/phi_c)/(K_HM + 4mu_HM/3) + (1-phi/phi_c)/(K0 + 4mu_HM/3) ]^-1 - 4mu_HM/3; mu_dry = [ (phi/phi_c)/(mu_HM + z_HM) + (1-phi/phi_c)/(mu0 + z_HM) ]^-1 - z_HM, z_HM = mu_HM/6 (9K_HM + 8mu_HM)/(K_HM + 2mu_HM). STIFF SAND (modified HS upper): same form but z computed from mineral K0,mu0 instead of HM. the reference suite outputs lower/upper/average. CEMENTED SAND (Dvorkin-Nur 1996): Kdry = n(1-phi_c) Mc Sn / 6; mu_dry = 3Kdry/5 + 3 n (1-phi_c) mu_c St / 20; Mc = rho_c Vp_c^2, mu_c = rho_c Vs_c^2 of cement; Sn(alpha, Lambda_n), St(alpha, Lambda_t, nu) are the published statistical polynomial fits; cement radius ratio alpha: scheme1 (cement at contacts) alpha = 2[(phi_c - phi)/(3 n (1-phi_c))]^0.25, scheme2 (uniform coating) alpha = [2(phi_c - phi)/(3(1-phi_c))]^0.5. Input phi clamped to <= phi_c. Then Gassmann-saturate all variants (mod_sat equations) and Vp/Vs/rho as usual.

Inputs: KMOD_MIN, UMOD_MIN, RHO_MIN, KMOD_FL, RHO_FL, PHIE, PRESS_EFF_OB (kPa), model + coordination option + n, phi_c (0.36), cement DT/DTS/RHO + deposition scheme (cementation only).
Outputs: KMOD/UMOD_DRY, KMOD/UMOD_SAT (+ HSL/HSU/HS_AVG variants for MODIFIED_HS), DT/DTSM/VELC/VELS_SAT (+bound variants), RHOB_SAT, COORD_x.
Calibration: Rock-physics diagnostics workflow (Avseth): plot measured wet-sand Vp(phi) against soft-sand, stiff-sand, cement-model curves to diagnose diagenesis; tune n, phi_c, cement fraction until model line tracks data; QC modeled vs measured DT and DTS overlays.

### Xu-White (clay-sand) and Xu-Payne (carbonate) + KT/SCA/DEM effective medium - ADVANCED/LATER phase
Inclusion-based models. Xu-White: porosity split by Vsh into sand pores (AR 0.12) and clay pores (AR 0.03), Kuster-Toksoz dry frame (Keys-Xu 2002 approximation), Gassmann saturate. Xu-Payne extends to carbonates with 4 pore families (clay 0.03, interparticle 0.15, microcrack 0.02, moldic/vug 0.8), Wyllie interparticle reference trend partitions porosity, DEM builds frame, isolated pore fractions (water-filled, VOL_ISO defaults 1.0) added to frame because Gassmann invalid for isolated pores. Generic module offers KUSTER-TOKSOZ (valid only dilute: vol/AR<=1), Berryman SELF-CONSISTENT (needs grain AR), DEM, each with low-freq (dry+Gassmann) vs high-freq (direct fluid inclusion) switch. Recommend: defer implementation, but design the module registry so these slot in; Mahakam is clastic so Xu-White is the only one with near-term value.

Equations:
Kuster-Toksoz: (K_KT - Km)(Km + 4mu_m/3)/(K_KT + 4mu_m/3) = SUM_i xi(Ki - Km)P^mi; similar zeta-form for mu with Q^mi; P,Q tensors are the published aspect-ratio functions (RPH ch.4.8). DEM: ODE d[K*(y)]/dy = (K2 - K*)P(y)/(1-y), y = inclusion concentration, integrate numerically from mineral. SCA: SUM_i xi(Ki - K_sc)P*i = 0 solved iteratively. Keys-Xu 2002: analytic approximation of DEM for the two-pore-type case (paper: Geophysics 67, 1406-1414). Xu-Payne partitioning: Wyllie trend Vp_ref(phi) through interparticle AR; measured Vp> ref => allocate stiff-pore volume, < ref => crack volume; ERR_DT = DT_measured - DT_modeled.

Inputs: Xu-White: Vsh, PHIT, sand matrix DT/DTS/rho (166/256 us/m, 2650), shale DT/DTS/rho (230/394/2650), aspect ratios (0.12/0.03), KMOD_FL, RHO_FL. Xu-Payne: PHIT, DT, VSH, 4 aspect ratios, VOL_ISO_MICROCRACK/VUG, KMOD/UMOD/RHO_MIN, KMOD/RHO_FL. Generic: POAR + VOL_POAR arrays, grain AR (SCA).
Outputs: KMOD/UMOD_DRY, KMOD/UMOD_SAT, DT/DTSM/VELC/VELS_SAT, RHOB_SAT; Xu-Payne also ERR_DT (QC), pore-type volumes, VOL_MICROCRACKS_VUGS (-1..1 colormap log).
Calibration: Aspect ratios are the free parameters: adjust until ERR_DT ~ 0 in intervals of known pore type; Xu-Payne crossplot Vp vs phi colored by VOL_MICROCRACKS_VUGS against the AR family template curves.

### Reflectivity / impedance / synthetics - SCOPE BOUNDARY
IN SCOPE (cheap, log-domain, from tp_reflectivity.info): acoustic impedance ACI = rho*Vp, shear impedance rho*Vs, LNRV = ln(ACI), normal-incidence reflectivity REFC_i = (ACI_{i+1} - ACI_i)/(ACI_{i+1} + ACI_i), integrated reflectivity REFI = running sum, Connolly-1999 elastic impedance EI(theta) = Vp^(1+tan2th) Vs^(-8K sin2th) rho^(1-4K sin2th) with K=(Vs/Vp)^2 avg (warn if Vs/Vp>0.8), single-angle Zoeppritz (or Aki-Richards 3-term: R(th) = R0 + G sin2th + F(tan2th - sin2th)) AVO log, AVO intercept-gradient R0-G for crossplot classes. OUT OF SCOPE initially (the reference suite delegates to tp_synthetic/tp_avo chain): depth-to-time conversion via checkshot/TWT, wavelet extraction, Ricker convolution trace generation, multi-offset gather synthesis, stacking, display polarity conventions. Recommendation: implement the impedance/reflectivity/EI/AVO-attribute LOG outputs now (they feed the crossplot module and Gassmann QC via LNRV before/after), defer time-domain synthetics to a later SandiBumi phase; note the reference suite's Gassmann+Synthetic script pattern (run Gassmann for WET/OIL/GAS/LSG then synthetic per fluid, display side-by-side) as the eventual target workflow.

Equations:
See summary (all standard; REFC/ACI/LNRV/EI forms verbatim from tp_reflectivity.info, Aki-Richards from literature).

Inputs: DT, DTSM, RHOB, angle theta; optionally TWT log for future time conversion.
Outputs: ACI, ACI_S, LNRV, REFC, REFI, EI(theta), AVO R(theta), R0, G.
Calibration: None per se; QC = LNRV_IN vs LNRV_SUBS change consistent with fluid change direction (gas lowers impedance).
