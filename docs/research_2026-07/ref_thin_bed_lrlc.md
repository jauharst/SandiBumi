## Methods
### Thomas-Stieber shale-distribution decomposition (1975)
Crossplot of gamma-ray index vs total porosity decomposes total shale into laminated vs dispersed (optionally structural) fractions and recovers sand-lamina porosity, under a binary sand/shale model with constant end-members. The foundational volumetric model reused by VLSA-era, Mollison/LSSA, Yadav, Madjid-Worthington and Sahari workflows.

Equations:
Gamma index: gamma = (Rb - R)/(Rb - Ra) with Ra = clean-sand GR, Rb = pure-shale GR (gamma=1 clean sand, 0 shale). Radioactivity scale factor: xi = Rb/(Rb - Ra) (paper example xi=1.25 for Ra=20, Rb=100 API). Dispersed (pore-filling, Xsh <= phi_a): Xsh = (1-gamma)/xi; phi_dis = phi_a - Xsh*(1 - phi_b) = phi_a - ((1-gamma)/xi)*(1-phi_b). Dispersed beyond fill-up (Xsh > phi_a): gamma = 1 - Xsh; phi_dis = phi_b*(1 - gamma)... wait, printed Eq 22 is phi_dis = phi_b - gamma*phi_b = phi_b(1-gamma). Minimum dispersed porosity: phi_min = phi_a*phi_b at Xsh = phi_a. Laminated: gamma = Xa = sand fraction; phi_lam = gamma*phi_a + (1-gamma)*phi_b (straight line between end points). Structural: phi_str = phi_a + (1-gamma)*phi_b (porosity INCREASES with structural shale); max structural Xsh = 1-phi_a. Triangle construction: apex1 (gamma=1, phi_a), apex2 (gamma=0, phi_b), dispersed vertex (phi_a*phi_b at gamma from Eq 20, ~0.588 in example). Iso-lamination lines parallel to dispersed line; iso-sand-porosity lines fan from gamma=0 apex to the dispersed line. Modern parameterization (as used by Mollison/Yadav): axes Vsh(total) vs PHIT with points phi_max (clean sand), phi_sh, phi_min = phi_max*phi_sh; laminated line PHIT = phi_max - (phi_max - phi_sh)*Vlam; dispersed line PHIT = phi_max - Vdisp*(1 - phi_sh)... i.e. Mezzatesta Eq (11): phi_t = phi_max - (phi_max - phi_shl)*Vshl - (1 - phi_shd)*Vshd + phi_shs*Vshs. Laminated resistivity companion (paper Eq 31): 1/Ra = f_sd/R_sd + f_sh/R_sh.

Inputs: GR (or any linear shale-index log: SP, N-D separation, resistivity per the seminar deck), PHIT (density porosity preferred per practice notes), end-member parameters: GR_clean (Ra), GR_shale (Rb), phi_max (clean-sand porosity), phi_sh (shale porosity). Hydrocarbon-corrected density/neutron required in HC zones (TS assumes water-bearing response).
Outputs: Vlam (laminated shale fraction), Vdisp (dispersed shale fraction, sand-referenced or bulk), sand fraction (net-to-gross = 1-Vlam), sand-lamina total/effective porosity phi_tsd / phi_esd, shale-distribution class per depth; feeds laminated resistivity correction for Sw.
Calibration: Pick phi_max and phi_sh from crossplot cluster extremes or core; verify shale cluster stationarity zone-by-zone (Yadav: plot shale cluster per depth zone, refine phi_max/phi_sh until TS Vlam matches image-log/tensor Vlam); validate against core photo lamina counts (original paper: 31% sand porosity + 15% shale porosity reproduced density log average). Constrain to laminated-dispersed (no structural) in most workflows. GR index must be corrected to true Vsh (Larionov/Clavier/Steiber or XRD) before use.

### Bateman binary-lithology thin-bed analysis (1990) — conventional suite only
Thin-bed evaluation from a plain triple combo (no image log): converts a conventional Vsh curve into a binary sand/shale column via a two-filter adaptive technique, enhances induction conductivity to Vsh resolution using a pseudo-conductivity trick, then evaluates each sand lamina as clean Archie rock. Resolves beds to ~3 in at 4-10 samples/ft.

Equations:
(1) Binary lithology: filter Vsh with short (~1 ft, e.g. 5 weights at 4 s/ft) and long (~3 ft, 15 weights, sinusoidal shape, long = 3x short) filters; dVsh = Vsh_long - Vsh_short; boundary picks where scale_factor*dVsh crosses original Vsh; sand where short<long, shale where short>long. Monitor curve = integral(binary shale beds) - integral(conventional Vsh) — tune scale_factor (start ~10) until monitor hovers at zero (V-shale-feet conserved). (2) Conductivity enhancement: laminated response Ct = Vsh*Csh + (1-Vsh)*Csd; pseudo curve CSHVSH = Csh*Vsh (Csh from induction in thick shale; assumes Csd negligible, ~25:1 contrast); smooth CSHVSH with induction vertical geometric factor (~12 ft filter) -> CVBAR; dC = CSHVSH - CVBAR; enhanced conductivity CILD* = CILD + dC; RtStar = 1/CILD*. (3) Lamina petrophysics: phi_Lam = phi_e/(1 - Vsh) (redistribution of void space, guard Vsh<1); Sw_Lam^n = F*Rw/RtStar with F from phi_Lam (clean Archie); HCPV = phi_Lam*(1-Sw_Lam)*h per sand bed; accumulate net sand count, pay flags with cutoffs.

Inputs: Vsh curve from conventional shaly-sand analysis (GR/neutron-density), deep induction conductivity CILD (or RILD), effective porosity phi_e, Rw, Archie a/m/n, Csh (shale conductivity from log inspection), sample rate (2/4/10 per ft supported), filter lengths, binary scale factor.
Outputs: Binary sand/shale lithology column, enhanced RtStar (CILD*), sand-lamina porosity phi_Lam, Sw_Lam, permeability estimate, net sand count, pay flags, level-by-level engineering listing (PHILAM, SWLAM, HCPV, cumulative HCPV/pay/perm).
Calibration: Scale factor tuned via zero-mean monitor curve (integrated Vsh conservation); verify bed resolution against dipmeter/borehole image where available (paper: 3-in agreement); check porosity/permeability against sidewall cores; compare pay count vs conventional analysis (Vicksburg example: 40.25 vs 26.25 pay-ft, +50% HCPV). Caveats: assumes truly binary (clean sand/pure shale) laminae; deconvolution noise-sensitive; run alongside dispersed shaly-sand model and choose by geology.

### Passey VLSA — Volumetric Laminated Sand Analysis (2006, AAPG Archie #1 Ch12)
Interval-based (not depth-by-depth) Monte Carlo inversion of interval-average log values against an a priori statistical earth model of bed-type properties; outputs posterior distributions of sand fraction, sand porosity, sand Sw and HPT with explicit uncertainty. Avoids the error-amplification of solving Poupon Eq 1.9 for Rsd. This is what Jauhar calls 'Passey VLSA'.

Equations:
Interval-average forward models (2 bed types): D_int = v_sd*rho_sd + v_sh*rho_sh (12.1); rho_sd = (1-phi)*rho_ma + phi*rho_fl (12.2); v_sd + v_sh = 1 (12.3); sigma_IL = v_sd*sigma_sd + v_sh*sigma_sh (12.4, valid borehole-perpendicular; use conductivity averages, never reciprocal of averaged R); sigma_sd = sigma_w*phi^m*Sw^n (12.5, Archie; W-S or dual-water allowed; shale: Sw=1); GR analog with GR endpoints. Dip: sigma_IL = sqrt(sigma_p^2*cos^2(theta) + sigma_p*sigma_t*sin^2(theta)) (Moran-Gianzero, Eq 6.8/10.13); triaxial z-component sigma_z = sigma_p*sin^2(theta) + sigma_t*cos^2(theta) (10.14); sigma_p = sum(v_i*sigma_i) (10.9), sigma_t = [sum(v_i/sigma_i)]^-1 (10.10). Log-average uncertainty: u^2 = a^2 + r^2/N (12.6). Probability index per log: P = exp(-0.5*((L-M)/E)^2) (12.7); joint JPI = product(P_i) (12.8); weight realization by trunc(10*JPI) counts (JPI<0.1 discarded). HPT = h*phi*(1-Sw) summed; NMR check HPT = h*sum(FF_i) (12.9). Isotropic-property averages for any earth model: phi_t = sum(v_i*phi_ti) (6.1); phi_t*Swt = sum(v_i*phi_ti*Swti) (6.2); rho_b = sum(v_i*rho_bi) (6.3); (1-phi_t)*rho_ma = sum((1-phi_ti)*v_i*rho_mai) (6.4). Finite-lateral-extent beds via EMT with aspect ratio alpha = bv/bh (6.7).

Inputs: Interval averages + assigned std devs of GR, RHOB, deep conductivity (and optionally vertical/transverse conductivity from triaxial induction, NMR); a priori truncated-normal distributions (mean/sd/min/max) for: Cw, relative dip, interval thickness h, Vsand/Vshale (uniform 0-1), PHIT_sand, PHIT_shale, SWT_sand (e.g. uniform 0.05-0.45), m, n, Ct_shale, rho_ma, rho_fl, GR endpoints. Requires independent confirmation the interval IS thin-bedded (core, image, NMR).
Outputs: Posterior distributions (histograms, mean/sd/P5/P10/P50/P90/P95) of sand volume fraction, sand porosity, sand Swt, and interval HPT; post-inversion parameter correlations (e.g. Vsand-Sw). Book example: 28,000 realizations -> 1000 accepted; HPT 1.51 +/- 0.16 m vs core 1.5 m vs conventional 0.3 m. Adding sigma_v: sand Sw error 39%->14%, sand fraction 12%->6%.
Calibration: Tighten priors with core (sand phi, m, n), thick-shale log readings (shale phi, Ct_sh); initial volume fractions from least-squares prefit; relative log std devs set relative weights (GR weighted least); avoid shoulder-affected samples in averages; need >=500 accepted independent samples; tens of thousands of realizations typical. Limitations: linear/convolution response assumption, no invasion/borehole effects, laterolog+dip not modeled, interval-average only (no depth-by-depth curve).

### Tensor resistivity primitives + Klein anisotropy petrophysics (Klein et al. 1995/1997)
Core physics shared by all Rv/Rh methods: parallel (arithmetic conductivity) and series (arithmetic resistivity) mixing across laminae, transversely-isotropic conductivity tensor, Moran-Gianzero apparent resistivity under relative dip. Klein adds: anisotropy is saturation-dependent (peaks near macro-layer Swirr, near-isotropic in water leg) -> the Rv-vs-Rh crossplot ('Klein plot') discriminates thin-bed pay; and permeability transforms must swap: k_parallel correlates with R_perpendicular.

Equations:
R_perp (=Rv) = V_M*R_M + V_mu*R_mu (arithmetic, dominated by resistive/hydrocarbon layers); 1/R_par (=1/Rh) = V_M/R_M + V_mu/R_mu (harmonic, dominated by conductive shale); anisotropy ratio = R_perp/R_par >= 1. Per-layer Archie R_i = a*Rw/(phi_i^m*Swi^n) (Klein used a=1,m=n=2); layer Sw_i(h) from capillary pressure (Thomeer fit to MICP); composite Swt = sum(V_i*phi_i*Swi)/sum(V_i*phi_i). Induction tensor: sigma-hat = diag(sigma_h, sigma_h, sigma_v); rotated sigma' = R^T*sigma-hat*R; apparent sigma_IL = sqrt(sigma_h^2*cos^2(theta) + sigma_h*sigma_v*sin^2(theta)). Permeability: k_h(parallel flow) = sum(V_i*k_i) arithmetic; k_v = [sum(V_i/k_i)]^-1 harmonic; since layer k ∝ layer R (Coates-type k = f(phi, BVirr): Coates free-fluid k^0.5 = (100*phi^2)*(phi-BVI)/BVI form), k_parallel ∝ R_perpendicular and k_perpendicular ∝ R_parallel (hydrocarbon zones at Swirr; in water zones k ∝ C in matching directions). Klein plot: log-log Rv vs Rh; isotropic line Rv=Rh; points move NW (high Rv/Rh) with laminated pay; overlay iso-Rsand and iso-Fsand (N:G) grid computed from the two mixing equations — exactly what Jauhar's 'Klein plot trial.xlsx' prototypes.

Inputs: Rv and Rh (measured by triaxial induction, LWD at high angle, or synthesized), or layer-model inputs (V_i, phi_i, MICP/Thomeer parameters, Rw, m, n, FWL) for forward modeling; for the plot: Rsh_h, Rsh_v endpoint (thickest shale), Rsand family.
Outputs: Anisotropy ratio log; pay/non-pay discrimination via Klein plot domains (shale point, water-leg trend, HC-bearing NW excursion); N:G and Rsand estimates read from crossplot grid; direction-correct permeability predictions; forward-modeled Rv/Rh logs from a high-res earth model (average detailed logs arithmetically in C and in R).
Calibration: Pick shale point (Rsh_h, Rsh_v) from thickest shale on the plot (Sahari's 'modified Klein plot'); water-leg interval defines isotropic baseline; validate saturation-dependence with lab cube measurements or MICP-driven layer model; erroneous shale anisotropy endpoints bias Rsand optimistic/pessimistic.

### Hagiwara Rv/Rh laminated-sand Sw (specced from literature; no classic-paper file in library)
Closed-form inversion of the two tensor mixing equations for laminar shale fraction Vshl and laminar sand resistivity Rsd from measured Rv, Rh and a shale resistivity; then Archie/Waxman-Smits on the sand fraction. Hagiwara (SPE-28426 1994; TLA 1995-1998) established the anisotropy interpretation and N:G-from-lambda relations; identical algebra appears as Fanini et al. 2001 Eqs in Madjid-Worthington (which IS in the library). His only file in the folder is the 2023 ML deconvolution paper (separate method below).

Equations:
System: 1/Rh = Vshl/Rsh_h + (1-Vshl)/Rsd; Rv = Vshl*Rsh_v + (1-Vshl)*Rsd. Isotropic shale (Rsh_h=Rsh_v=Rsh) closed forms (Fanini/Madjid-Worthington printing): Rsd = Rh*(Rv - Rsh)/(Rh - Rsh) [eq 3]; Vshl = (Rsd - Rv)/(Rsd - Rsh) [eq 4]. Equivalent direct form: Vshl = Rsh*(Rv - Rh)/(Rh*Rv - 2*Rh*Rsh + Rsh^2), then Rsd = (Rv - Vshl*Rsh)/(1 - Vshl). If Vshl known independently (image log / TS): Rsd = (1-Vshl)*[(1/Rh) - Vshl/Rsh_h]^-1 [eq 1, parallel] and Rsd = [Rv - Vshl*Rsh_v]/(1-Vshl) [eq 2, series]; agreement between the two is a QC on Vshl. Anisotropy: lambda^2 = Rv/Rh = [Vshl*Rsh + (1-Vshl)*Rsd]*[Vshl/Rsh + (1-Vshl)/Rsd] (max where fractions ~50/50). Anisotropic shale: unknowns Vshl, Rsd with Rsh_h != Rsh_v picked from Klein plot; same two equations. Sw: Swsd = [a*Rw/(Rsd*phi_tsd^m)]^(1/n) or Waxman-Smits with Qv of dispersed clay only. Deviated-well note: measured pair must be true Rv/Rh from triaxial inversion; a conventional induction gives only sigma_IL(theta) (Moran-Gianzero).

Inputs: Rv, Rh (multicomponent induction e.g. 3DEX/Rt Scanner, or LWD in high-angle wells, or Elhadidy-style multi-well derivation), Rsh_h and Rsh_v (thick-shale readings / Klein plot), optionally independent Vshl (image log, TS), phi_tsd, Rw, m, n (pseudo-Archie from SCAL).
Outputs: Vshl (laminar shale fraction / N:G complement), Rsd (laminar sand resistivity), sand-fraction Swsd, anisotropy ratio curve; QC delta between parallel- and series-derived Rsd.
Calibration: Cross-validate Vshl(tensor) against Vshl(Thomas-Stieber) and image-log counts — agreement is the key QA (Yadav, Mollison); shale endpoint anisotropy from Klein plot in thickest shale; guard domains: Rh <= Rv, Rsd > Rsh required for stability; solution degenerates as Rv->Rh (isotropic) — cap Vshl in [0,1] and damp near-singular (Rh ~ Rsh) cases.

### Mollison / Mezzatesta LSSA — full tensor + multi-shale simultaneous inversion (SPWLA 2002)
The complete Baker-Atlas laminated shaly-sand interpretation model: simultaneous nonlinear weighted least-squares solution for five fundamental volumes (laminar/structural/dispersed shale, irreducible and movable water) honoring conventional logs, tensor resistivity, NMR volumes, and optional permeabilities, with Thomas-Stieber-style replacement laws as constraints. The rigorous 'do-everything' version of the thin-bed module.

Equations:
Bulk volumes: Vma + Vshl + Vshs + Vshd + Vw + Vhc = 1 (1); sand-referenced (subscript sd, normalized to laminar-sand fraction): Vma_sd + Vshs_sd + Vshd_sd + Vw_sd + Vhc_sd = 1 (2); Vshd = Vshd_sd*(1 - Vshl) (3). Replacement laws: phi_max*(1-Vshl) = Vshd + Vw + Vhc (4); (1-phi_max)*(1-Vshl) = Vshs + Vsd (5). Range constraints: 0 <= Vshd <= phi_max*(1-Vshl) (6); 0 <= Vshs <= (1-phi_max)*(1-Vshl) (7); 0 <= Vh <= phi_max*(1-Vshl) - (Vw+Vshd) (23). Shale bound water: Vwshl = phi_shl*Vshl, Vwshs = phi_shs*Vshs, Vwshd = phi_shd*Vshd (8a-c). phi_t = Vwshl + Vwshs + Vwshd + Vw + Vhc (9); Vsh_total = Vshl + Vshs + Vshd (10); phi_t = phi_max - (phi_max - phi_shl)*Vshl - (1 - phi_shd)*Vshd + phi_shs*Vshs (11). Generalized log response: P = Psd*Vsd + Pshl*Vshl + Pshs*Vshs + Pshd*Vshd + Pw*Vw + Phc*Vhc (12) for GR/neutron/density/acoustic. Tensor: 1/Rh = Vshl/Rshl_h + (1-Vshl)/Rsd (13); Rv = Vshl*Rshl_v + (1-Vshl)*Rsd (14). Sand resistivity Waxman-Smits: Rsd = a*Rw/(phi_tsd^m* * (1 + Rw*B*Qvd_sd*Swt_sd^-1) * Swt_sd^n*) (15); Qvd_sd via Hill-Shirley-Klein 1979; B via Juhasz 1981/1986. NMR: BVI = Vwirr (16); BVM = Vwm + Vhc (17); CBW = phi_shl*Vshl + phi_shs*Vshs + phi_shd*Vshd (18). Permeability: kv = Vshl*kshl_v + (1-Vshl)*ksd (19); 1/kh = Vshl/kshl_h + (1-Vshl)/ksd (20) [NOTE: as printed these are swapped vs physics — parallel-to-bed flow (kh) should be arithmetic; flag in implementation]; Coates-Timur sand: ksd = (phi_tsd/C)^a * (BVI_sd/BVM_sd)^b (21) [as printed; standard Coates uses (BVM/BVI) or (FFI/BVI) — likely typo, verify sign of exponent b]. Objective: H(p) = ||Wd(f(p)-d)||^2 + ||Wc(g(p)-h)||^2 + ||Wp(p - p_ref)||^2 (24); Newton iteration, Marquardt-Levenberg + SVD; reference model p_ref = previous depth solution (smoothness).

Inputs: phi_t, Vsh_total (analyst or log-derived), density, neutron, GR, acoustic, Rv + Rh (3DEX-class), NMR BVI/BVM/CBW, optional kh/kv from testing; parameters: phi_max, phi_shl/phi_shs/phi_shd, Rshl_h, Rshl_v, Rw, B, m*, n*, CEC/Qv model, Coates C/a/b, endpoint response values for each log and component.
Outputs: Per depth: Vshl, Vshs, Vshd, Vwirr, Vwm, Vhc, Vsd; sand-referenced phi_tsd/phi_esd, sand Swt (irreducible + movable split), ksd, kh, kv; parameter confidence intervals from sensitivity analysis; total/effective porosity and bulk renormalized volumetrics.
Calibration: Endpoint selection from N-D and GR-D crossplots overlain by TS triangle (HC-corrected); shale resistivity anisotropy from thick shales/Klein plot; Qv from core CEC (power-law vs porosity); weights Wd/Wc/Wp encode log quality; validate Vshl(tensor) vs Vshl(TS) agreement; Dean-Stark core Sw as ultimate ground truth (Sahari); synthetic-model validation via 3DEX forward modeling + inversion (paper's 500-layer/180-m test).

### Yadav et al. combined workflow (SPE 132970, 2010) — OBMI binary litho + sigma Vsh + TS + tensor
Field-proven integration for very thin beds (laminae ~1.2 cm, below OBMI resolution): Bateman-style binary lithology run on the OBMI pad-resistivity (SRES) shale volume gives laminar N:G calibrated to core LamCount; sigma-log gives total Vsh; Thomas-Stieber splits laminar/dispersed and gives sand porosities; tensor resistivity gives laminar sand Rsd; Archie on the sand fraction; sand-referenced results renormalized to bulk for summations.

Equations:
Binary litho: Vsh from SRES; long+short filtering; dVsh = long - short; sand if Vsh < filtered Vsh crossing criterion; net sand = integral of sand flags (restricted to integral(1-Vsh)). LSSA steps: Vsh_total from sigma (linear XRD-Vclay vs sigma calibration); PHIT from density (or D-N with light-HC correction factor ~0.5-0.63 from N-D crossplot perpendicular trend; rho_mf from GR-vs-RHOB extrapolation, e.g. 0.85 g/cc); TS model with phi_min = phi_max*phi_sh; laminar sand phi_tsd, phi_esd sand-referenced; Vdisp = Vsh_total - Vlam (normalized to sand); tensor model (anisotropic-shale-isotropic-sand): Rsd from Rv/Rh + user Rsh_h/Rsh_v -> Archie Swt_sd (dispersed clay <=5% so Archie adequate; else Waxman-Smits). Summations: CumNetSand = sum((1-Vlam)*RLEVEL); phi_e-m = sum(phi_esd*(1-Vlam)*RLEVEL); phi_hc-m = sum((1-Swe)*phi_esd*(1-Vlam)*RLEVEL). Sand-specific cutoffs (phi_esd >= 0.25, Swe <= 0.8 in the example) chosen from cumulative HC-m vs cutoff curves.

Inputs: OBMI/FMI SRES curve (or any high-res micro-resistivity), sigma (pulsed-neutron capture) log or other total-shale indicator, RHOB/NPHI, Rv/Rh from multicomponent induction, Rsh_h/Rsh_v, phi_max, phi_sh, Rw, m, n, core LamCount + XRD + Dean-Stark for calibration.
Outputs: Laminar N:G (binary litho + LamCount-calibrated), Vlam/Vdisp, phi_tsd/phi_esd, Rsd, Swt_sd/Swe_sd, sand-normalized and bulk-renormalized net sand, porosity-m, hydrocarbon-m, net pay with sand-specific cutoffs.
Calibration: Three-way consistency loops: (a) shale indicators — sigma vs N-D vs resistivity vs smoothed SRES vs LamCount overlay; (b) shaliness vs porosity — sigma and N-D ternary must agree across water sands->shales before HC zones; (c) Vlam(TS) vs Vlam(tensor) agreement confirms planar-bed assumption/bed continuity. TS zone definition: verify shale-cluster stationarity per fining-upward sequence; refine phi_max/phi_sh/Vsh model to match core.

### Elhadidy et al. (IPTC-20352, 2020) — Rv/Rh from CONVENTIONAL logs via multi-well dip fit
When no triaxial tool exists (Jauhar's usual case): exploit well-to-well variation in relative dip through the same correlatable zone. Fit Moran-Gianzero Ra(theta) to (apparent resistivity, relative dip) pairs from many wells to recover zone Rh and Rv (and separately shale Rh_sh/Rv_sh from the thickest shale); then use parallel/series equations with Vsh(GR) to produce continuous Rsand and re-run Archie. Unlocked ~9 ohm-m Rv vs 1 ohm-m conventional in Gulf of Suez; Sw dropped from 60-90% to 20-50%, confirmed by clean-oil production.

Equations:
Moran-Gianzero apparent resistivity: Ra(theta) = f(Rh, Rv, theta) with lambda = sqrt(Rv/Rh); explicit form Ra = Rh*lambda/sqrt(lambda^2*cos^2(theta) + sin^2(theta)) equivalently 1/Ra^2 = cos^2(theta)/Rh^2 + sin^2(theta)/(Rh*Rv) (figure equation not machine-readable in PDF; standard M-G form). Nonlinear least-squares over well set {(theta_i, Ra_i)} -> zone Rh, Rv; same fit on thick-shale readings -> Rh_shale, Rv_shale (assumed constant across field). Continuous curves: with Vsh(z) from GR and Rsand as unknown: 1/Rh(z) = Vsh/Rh_shale + (1-Vsh)/Rsand(z); Rv(z) = Vsh*Rv_shale + (1-Vsh)*Rsand(z); solve for Rsand(z) (they used zone-average Vsh ~20% for the fit stage); Sw via Archie with Rsand (or Rv). 

Inputs: Multi-well set (they used 29 wells) penetrating the SAME correlatable zone with varying relative dip (structural dip + well deviation), zone-average apparent deep resistivity per well, thick-shale apparent resistivity per well, relative dip per well, Vsh from GR, Rw/m/n.
Outputs: Zone Rh and Rv, field-constant Rh_shale and Rv_shale, continuous Rsand(z) and Rv(z)/Rh(z) reconstructions, corrected Archie Sw, LRP flags. Discrete zone values, unlike a real triaxial log.
Calibration: Requires careful zone correlation across wells (top consistency is the dominant error source); group wells by compartment/similar fluid saturation; assumes laterally uniform shale properties (acknowledge heterogeneity risk); validate against production (water cut) and N-D separation in clean sand; curve-fit quality on Ra-vs-theta plot is the QC.

### Madjid & Worthington scenario framework (SPE 163071, 2012) — bed-thickness-driven workflow selector + porosity clay-correction
Decision framework that picks the fit-for-purpose thin-bed workflow by bed-thickness scenario (A: 10-60 cm detectable/pluggable; B: 3-10 cm pluggable/identifiable; C: 1-3 cm identifiable only; D: <1 cm laminated — compositional TS/Juhasz only; E: mixed), plus the Vcm correction that fixes systematic overestimation of clay content (and hence underestimation of sand porosity) by conventional shale indicators. Ideal top-level architecture for the SandiBumi thin-bed suite.

Equations:
Tensor (Fanini): Rtsd = (1-Vshl)*[(1/Rh) - Vshl/Rshl]^-1 (1); Rtsd = [Rv - Vshl*Rshl]/(1-Vshl) (2) [agreement = confidence in Vshl]; Rtsd = Rh*(Rv-Rshl)/(Rh-Rshl) (3); Vshl = (Rtsd-Rv)/(Rtsd-Rshl) (4); forward checks Rh (5), Rv (6). Dispersed shale: Vshd = Vsh - Vshl (7); sand-referenced Vshds = Vshd/(1-Vshl) (10). Clay-mineral correction: rho_bc = rho_ma - phi_c*(rho_ma - rho_f) (8, clean-sand density from core porosity); Vcm = (rho_bc - rho_b)/(rho_ma - rho_sh) (9); correlate Vcm vs Vsh at cored levels -> correction factors K; apply to thin interval; Vcmds -> Vcmd -> Vcm. Shale porosity import: phi_tsh = (rho_ma - rho_sh)/(rho_ma - rho_cbw) (11). Sand porosities: phi_tsd = [phi_t - Vshl*phi_tsh]/(1-Vshl) (12); phi_esd = [phi_t - Vcm*phi_tsh]/(1-Vshl) (13). Compositional (Scenario D, from Juhasz 1986): Vshl = [phi_t - phi_max + Vsh*(1-phi_tsh)]/(1-phi_max) (14); phi_max = phi_tsd + Vshds*(1-phi_tsh) (15). Saturation: pseudo-Archie Swsd = (Rw/(Rtsd*phi_c^m))^(1/n) with m,n measured on core using simulated formation water (preferred over shaly-sand equations); fallback: saturation-height function.

Inputs: Bed-thickness characterization (core description/image log) to pick scenario; quad combo; multicomponent induction (Rh, Rv); electrical micro-imager Vshl (running fraction at induction resolution); core plug porosities + pseudo-Archie m/n from SCAL; Rshl from thick shale; rho_ma, rho_f, rho_sh, rho_cbw; Rw from dual-packer/DFA sampling.
Outputs: Scenario assignment per interval; Vshl, Vshd/Vcmds, Rtsd, phi_tsd, phi_esd, Swsd, hydrocarbon volumes with securable upside quantification; QC metric = mismatch of Rtsd from eq(1) vs eq(2).
Calibration: Groundtruth chain: core porosity -> rho_bc -> Vcm-vs-Vsh regression (K factors) from THICK beds in same depositional system, then exported to thin beds; image-log Vshl takes precedence over compositional; Vsh indicator choice (uranium-stripped spectral GR, sigma, NMR) still needs core groundtruth; scenario E zones the interval first. Assumes laminated and dispersed shales compositionally identical.

### Worthington LRP recognition screen (2000) + NMR quick-looks (Passey Ch12)
Screening layer before any thin-bed computation: classify candidate LRLC intervals by 4 manifestations (absolute low Rt; low contrast vs water leg; model-range exceedance; correct-but-pessimistic Sw vs production) and 6 causes (laminated sand/shale, fresh formation water, electronic-conducting minerals, fine grain size, internal microporosity, superficial microporosity), each mapped to an evaluation strategy. Complemented by two NMR quick-looks from Passey: T2 free-fluid presence distinguishes thin-bed pay from debrite/dispersed shaly non-pay; and direct HPT = h*sum(FFI) at irreducible conditions.

Equations:
Classification is rule-based (no equations): cause -> strategy table (laminated -> tensor/TS/VLSA suite; fresh water -> pseudo-Archie exponents / normalized Qv; conductive minerals -> multimin with conductive-matrix term; capillarity causes -> NMR/saturation-height, Buckles phi*Swirr=C). NMR: HPT = h*sum(FF_i) over interval (Passey Eq 12.9, valid light-HC at Swirr); free-fluid vs bound-fluid from T2 cutoff. Detection heuristics from decks: N-D crossover in laminated zones, GR moderately high with suppressed Rt ~ shale baseline, Rv/Rh >> 1, NMR FFV in 'shaly' interval, production/Dean-Stark mismatch vs computed Sw.

Inputs: Standard triple combo, Rxo/microlog, NMR T2 (BVI/FFI), any Rv/Rh, production/test data (water cut), core (Dean-Stark Sw, MICP, XRD, CEC), formation-water salinity.
Outputs: LRLC flag + cause classification per zone; recommended method routing into the thin-bed suite (which module to run); Buckles/microporosity diagnostics; NMR-based HPT and thin-bed presence indicator.
Calibration: Key-well concept: build validated reference interpretations on quality-assured key wells, then port to offset wells without new acquisition; NMR HPT requires known fluid type/viscosity and Swirr state; group intervals with common characteristics early.

### Hagiwara ML induction deconvolution (Petrophysics 2023) — optional resolution-enhancement module
Machine-learning deconvolution that inverts induction apparent resistivity to layer resistivity + bed boundaries extremely fast without an earth model: gradient-boosted-tree regressor mapping a sliding window of log10(Rapp) samples to log10(R) at the center depth. Demonstrated on a synthetic 2C40 (2-coil, 40-in, 20 kHz) tool; concept portable to a 'sharpened Rt' preprocessing step feeding conventional thin-bed analysis.

Equations:
Linear baseline: sigma_a(z_i) = sum_{k=-N..N} G_k*sigma(z_{i+k}) (1); inverse sigma(z_i) = sum a_k*sigma_a(i+k) (2); weights by regression (3); applied in log domain: log R(z_i) = sum a_k*log Ra(z_{i+k}) (4)-(5). ML version: R_ML(z_i) = F_ML(log Ra(z_{i-N})...log Ra(z_{i+N})) (6), F = LightGBM regressor; chosen window 21 points / 10 ft (tool aperture ~T-R offset + 3.3 ft each side); trained on 15,501 samples from 1,001 random layers (thickness 0.1-50 ft log-uniform, R 0.1-100 ohm-m log-uniform). Metric RMSLE(R): raw 0.44, linear decon 0.41, ML 0.14-0.17 on unseen models (0.02 train).

Inputs: Apparent resistivity curve resampled at constant rate (0.5 ft in paper), trained model per tool geometry; training requires a forward model of the tool to generate synthetic Rapp.
Outputs: High-resolution deconvolved resistivity R_ML with accurate bed boundaries; single-unknown-per-depth limitation (no invasion/multi-parameter).
Calibration: Window-size study per tool (5 ft too narrow; >20 ft overfits; 10 ft optimal for 2C40); train/test on independent random earth models; residual RMSLE as acceptance metric; retrain per tool type.
