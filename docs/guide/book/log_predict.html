Synthetic Log (KNN Predict)

Module id log_predict · category Prep

Synthetic log by distance-weighted K-nearest-neighbour regression: trains on this run's samples where the target and every predictor are present, then predicts the target wherever the predictors exist. Predictors are z-scored so no one curve's units dominate the distance.

prediction = Σ wi·yi / Σ wi over the K nearest training samples
wi = 1/(di + 1e-6), di = Euclidean distance in z-scored predictor space
MAX_RAW: OUT = max(raw, synthetic), the washout rule for RHOB, since bad hole only pushes RHOB down

Step by step: a synthetic log by nearest neighbours

Synthetic Log trains on this run's own samples (wherever the target and every predictor are present) and predicts the target everywhere the predictors exist, by distance-weighted K-nearest-neighbour regression in z-scored predictor space. No model file, no training session: the well is its own training set.

The picks

  • Target RHOB from GR / NPHI / DT, K 10: the shipped defaults.
  • OPT_COMBINE MAX_RAW, the washout rule: bad hole only pushes RHOB down, so taking max(raw, synthetic) repairs washed-out density while leaving every good sample exactly as logged.
  • Mask BADHOLE, the rule the pane documentation states: washed-out samples must never train the model, or the synthetic learns the washout it exists to repair.

Run and read

On these wells: 3 clean, and MAX_RAW raised 567 samples above the delivered density: the washout intervals, where the logged RHOB is mud-biased low and the synthetic (trained on good hole) reads the rock instead. RHOB_SYN beside RHOB in a track shows the repair exactly where the caliper says it should be, and nowhere else.

What the application enforces

Everything below is generated from the same manifest the application builds this module’s pane from — descriptions, defaults, sources, ranges and pre-run checks here are exactly what the running application enforces.

Facimage-style synthetic log: trains on the samples of THIS run where TARGET and every supplied predictor are present, then predicts TARGET everywhere the predictors exist by distance-weighted K-nearest-neighbour regression (predictors z-scored; training set decimated to ≤4000 points). OPT_COMBINE: SYNTHETIC writes the pure prediction; FILL_MISSING keeps the raw value where present; MAX_RAW takes max(raw, synthetic) — the washout rule for RHOB, since bad hole only pushes RHOB down. Output is named <TARGET>_SYN. Mask the run to good-hole intervals so bad samples never train the model.
