SW — Saturation-Height

Module id sw_height · category Saturation

Water saturation from height above the free-water level, through a fitted capillary-pressure model: the Leverett J-function (fit SWH_A/SWH_B from core Pc data via Import SCAL) or the Skelt-Harrison law. Below the FWL the result is 1; above it the result is limited to [SWT_IRR, 1]. Height is measured from TVD when a TVD curve is supplied, so deviated wells are not overstated.

Pc = 0.433·(RHO_W − RHO_HC)·h_ft  (psi; 0.433 psi/ft per unit sp. gravity)
J = 0.21645·Pc/IFT_RES·√(PERM/PHIE),  SWH = SWH_A·J^SWH_B
SKELT: SWH = 1 − SH_A·exp(−(SH_B/(h + SH_D))^SH_C)  (h in metres)

References

  • Leverett, M.C. (1941), Transactions AIME 142 - the J-function
  • Skelt, C. & Harrison, B. (1995), SPWLA - the height-saturation law

Step by step: saturation from height, with the fit chain shown

sw_height writes a saturation-versus-height curve from a fitted capillary-pressure model — the Leverett J-function here, with Skelt-Harrison one dropdown away. Its inputs are the end of a chain, and this walkthrough runs the whole chain on SANDI-01 so every number arrives with its origin attached.

Link one: a permeability log from the core calibration

The J-function needs a PERM curve and none existed. The por-perm transform module is built for exactly this: PT_A 17.92 / PT_B −2.203 are the ordinary least-squares fit of log₁₀(CPERM) on CPOR (as a fraction) over the 15 plugs of the SANDI-01 core delivery — R² 0.981 — and the module writes PERM from PHIE_DEN on all three wells (3 clean). The regression is the user's own calibration by design; the transform ships no coefficients.

Link two: the Leverett fit from the SCAL import

Importing the delivery's long-format Pc table (24 points, air-brine, lab σ·cosθ 72 dyn/cm — the recorded laboratory seed) makes the import itself report the J-fit: SWH_A 0.511, SWH_B −0.210, R² 0.586. Note that R² — it will matter below.

Link three: the run

  • FWL 1535 m MD — the gas-water contact read off the resistivity collapse between the two sands. SANDI-01 is vertical so MD = TVD; the pane measures height from a TVD curve when one exists, and this well carries none, so the measured-depth fallback applies — which is only legitimate because the well is vertical.
  • RHO_W 1.0 (the cited default) and RHO_HC 0.7 g/cc · IFT_RES 26 dyn/cm — the recorded vendor seeds for the reservoir fluid pair. On a real study these come from PVT and lab IFT; for the gas leg of a real field you would use the water-gas pair instead. Seeds are seeds, and the reference field says so.
  • SWH_A/SWH_B from the import's fit; SWT_IRR 0.16 as in the other saturation chapters.

Run and read — including the disagreement

On SANDI-01: 1 clean. Below the FWL the curve is 1 by definition; above it HAFWL rises to 35 m at the top of the log and the J-curve pulls saturation down. Now the honest part: in the gas leg the height model reads a median SWT_HGT 0.53 where the resistivity methods read ~0.16 at their floor. That gap is the R² 0.586 talking — a J-fit through 24 scattered synthetic Pc points is a weak law, and the height curve inherits every bit of that weakness. On a real study this comparison — height-model saturation against resistivity saturation, on one track — is the QC that decides whether the Pc data, the contacts or the resistivity picks need another look before anything ships.

What the application enforces

Everything below is generated from the same manifest the application builds this module’s pane from — descriptions, defaults, sources, ranges and pre-run checks here are exactly what the running application enforces.

SWH from height above the free-water level. LEVERETT: Pc = 0.433*(RHO_W-RHO_HC)*h_ft, J = 0.21645*Pc/IFT_RES*sqrt(PERM/PHIE), SWH = SWH_A * J^SWH_B (fit SWH_A/SWH_B from core Pc data via Import SCAL — the fit is reported there). SKELT (Skelt-Harrison): SWH = 1 - SH_A*exp(-(SH_B/(h+SH_D))^SH_C), h in metres (SH_B and SH_D are metres by the published form, so the height is converted for that branch alone — the HAFWL curve itself is written in the project's own depth unit). Below the FWL (h <= 0) SWH = 1. Result limited to [SWT_IRR, 1]. FWL is zone-overridable for stacked reservoirs with different contacts. Height is measured from the TVD input when a TVD curve is supplied (else measured depth) so deviated wells are not over-stated — MD height overstates true height by ~1/cos(inc); enter FWL on the SAME reference (a negative value for a sub-sea TVDSS FWL).
