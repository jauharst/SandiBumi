Porosity Ceiling (φmax)

Module id phimax · category Porosity

Caps an input porosity at the field's compaction-controlled ceiling: a constant, a linear TVDSS trend, or an Athy exponential trend. Writes the capped curve and the ceiling curve for QC; the input porosity is never modified.

constant: φmax = PHIMAX0
linear: φmax = PHIMAX0 − PHIMAX_GRAD·(TVDSS − TVDSS_REF)/1000
athy: φmax = PHIMAX0·exp(−ATHY_K·(TVDSS − TVDSS_REF)/1000)
<PHI>_CAP = min(PHI, φmax)

References

  • Athy (1930): the exponential compaction trend

Step by step: capping porosity at what the rock allows

A computed porosity can drift above what compaction allows: bad hole, a light mineral, an optimistic parameter. This module writes the capped copy and the ceiling itself, and never modifies the input curve.

Pick a ceiling from your own data

Open Petrophysics → Porosity → Porosity Ceiling (φmax). For a first look the constant mode is enough (the linear and Athy TVDSS trends are for fields with a real compaction profile and a deviation survey loaded). Entered here:

  • MODE constant, PHI input pinned to PHIE (the Porosity from Density run's output).
  • PHIMAX0 0.27, the P99 of that PHIE on SANDI-01: a ceiling read off this dataset's own distribution, recorded as exactly that in the reference field. It is a demonstration pick, not a recommended value; on a real field the ceiling is the crossplot "max core porosity" line.

Run and read

On these wells: 3 clean. Two curves come back: PHIE_CAP = min(PHIE, φmax) with MISSING preserved, and PHIE_MAX, the ceiling itself, which you drop onto the log view as a QC overlay. Wherever the porosity curve rides the ceiling, the cap is doing work and you should ask why.

What the application enforces

Everything below is generated from the same manifest the application builds this module’s pane from — descriptions, defaults, sources, ranges and pre-run checks here are exactly what the running application enforces.

Caps an input porosity at a maximum ceiling — the field's compaction-controlled upper limit (the crossplot 'max core porosity' line). The ceiling is CONSTANT (PHIMAX0, per-zone overridable), or a TVDSS compaction TREND: LINEAR (φmax = PHIMAX0 − PHIMAX_GRAD·(TVDSS − TVDSS_REF)/1000) or ATHY exponential (φmax = PHIMAX0·exp(−ATHY_K·(TVDSS − TVDSS_REF)/1000)). TVDSS is a POSITIVE-downward depth-below-datum curve (same convention as precalc), so DEEPER = larger TVDSS = lower ceiling; all four params are per-zone overridable. No TVDSS curve → measured DEPTH is used instead (fine for near-vertical wells; the trend then reads against MD). Writes <PHI>_CAP = min(PHI, φmax) preserving MISSING, and the ceiling curve <PHI>_MAX for QC overlay; the input porosity is never modified. Constant mode ignores TVDSS.
