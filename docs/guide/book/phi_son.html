Porosity from Sonic

Module id phi_son · category Porosity

Sonic porosity with three transforms, each named for what it computes: the Wyllie time-average, the genuine three-segment Raymer-Hunt-Gardner 1980 transform, and the field-observation transform with a cited coefficient. Wyllie is shale-corrected subtractively and optionally compaction-corrected; the other two use the normalised shale convention.

WYLLIE: PHIT = (DT − DT_MA)/(DT_FL − DT_MA)   [÷ Cp, Cp = DT_SH/100, when OPT_CP = ON]
RHG80: φ < 37%: invert V = (1−φ)²·Vma + φ·Vf;  φ > 47%: fluid-suspension form;  37–47%: Δt-linear interpolation
FIELD_OBSERVED: PHI = CFO·(DT − DT_MA)/DT
Non-Wyllie shale convention: dtsr = (DT − VSH·DT_SH)/(1 − VSH), floored at DT_MA; PHIE = transform(dtsr)·(1 − VSH)

References

  • Raymer, Hunt & Gardner, SPWLA 21st Annual Logging Symposium, 1980, paper P
  • Wyllie (1956/1958) - the time-average transform

The Raymer-Hunt-Gardner constants are verified against a copy of the paper held in the project library; the Wyllie citation is the author-year lead as this project's method ledger records it.

Step by step: porosity from the sonic

Three transforms live in this pane, each named for what it actually computes — Wyllie time-average, the genuine three-segment Raymer-Hunt-Gardner 1980, and the field-observation transform with its cited coefficient. This run uses WYLLIE, the default and the one convention every installed tool agrees on exactly.

Enter the endpoints

DT_MA and DT_SH ship without defaults — the pane's shipped-values list shows why: the installed tools carry four different sandstone matrix slownesses (53.0 to 56.0 µs/ft), and shipping one would silently pick a vendor for you. Entered here:

  • DT_MA 55.5 µs/ft — chosen off the pane's own source list: the Geolog shipped Wyllie default. The choice and its source went into the run's reference field.
  • DT_SH 118 µs/ft — the median DT of SANDI-01's samples at GR ≥ 112 gAPI, this dataset's own shale.
  • DT_FL 189 µs/ft — the shipped default (water), left alone.

The pane enforces DT_MA strictly below DT_SH before the run — an inverted pair would turn the shale subtraction into an addition, so it is refused, not computed.

Run and read

On these wells: 0 clean · 3 degraded — the per-well report lists per-sample clamps where the limited PHIE was held against its ordering bound (PHIE can never exceed what the shale correction leaves of PHIT). A sonic in shaly rock rides its bounds more than a density does; the unlimited PHIT_SON/PHIE_SON beside the limited curves show exactly what was clipped and where.

If you switch to RHG80, RHO_MA becomes required (the paper's own density pairings) and the compaction option disappears — RHG is self-compacting, and the pane refuses the Wyllie Cp correction anywhere it would not mean what the paper meant.

What the application enforces

Everything below is generated from the same manifest the application builds this module’s pane from — descriptions, defaults, sources, ranges and pre-run checks here are exactly what the running application enforces.

Sonic porosity, three transforms each named for what it computes (SB-POR-014). WYLLIE: PHIT = (DT - DT_MA)/(DT_FL - DT_MA), shale-corrected SUBTRACTIVELY for PHIE - the one convention both vendors agree on exactly (SB-POR-013). RHG80: the genuine three-segment Raymer-Hunt-Gardner 1980 transform (DEC-017; primary source: Raymer, Hunt & Gardner, SPWLA 21st Annual Logging Symposium 1980, paper P, copy in Jauhar's library; constants paper-verified under DEC-079): phi < 37% inverts V = (1-phi)^2*Vma + phi*Vf as the quadratic root, phi > 47% inverts the fluid-suspension form (needs RHO_MA/RHO_FL, the paper's own density pairings), 37-47% is the paper's dt-linear interpolation. FIELD_OBSERVED: PHI = CFO*(DT - DT_MA)/DT with a CITED coefficient (Geolog CFO default 0.67, normal range 0.625-0.70; Techlog ships 0.625) - the transform the pre-DEC-017 build mislabelled RHG; the old option value RHG no longer resolves. Non-Wyllie methods use the NORMALISED shale convention per Geolog's EXECUTED code (SB-POR-013/-015, F4): dtsr = (DT - VSH*DT_SH)/(1 - VSH) floored at DT_MA (the Jul-1997 floor, F5), then PHIE = transform(dtsr)*(1 - VSH). OPT_CP=ON applies the Wyllie lack-of-compaction correction (Cp = DT_SH/100) to WYLLIE only: it requires DT_SH >= 100 us/ft (Cp >= 1) and the run is refused otherwise (DEC-012, SB-POR-017) - below 100 the division would inflate porosity, the opposite of its purpose. RHG80 and FIELD_OBSERVED are self-compacting and never Cp-corrected. DT_MA must be strictly below DT_SH (DEC-063) - an inverted pair turns the shale subtraction into an addition and is refused before the run. PHIT_SON/PHIE_SON are the bare unlimited expressions; PHIT/PHIE carry the unit-interval and ordering clamps.
