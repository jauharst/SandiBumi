SSPW — Sandstone Petrophysical Workflow

Module id sspw · category Porosity

Bound-water porosity split: effective porosity is total porosity minus clay-bound water only, capillary-bound water stays inside PHIE, and PHIFF is the porosity that flows. Outputs the bound-water volumes and irreducible saturation.

PHIE = PHIT − CBW  (clay-bound water only)
PHIFF = PHIT − CBW − CAPBW
Gas conditioning corrects the density leg only (same c parameter as SSC)

Step by step: the bound-water split

SSPW is SandiBumi's own bound-water workflow, and its message is one sentence: effective porosity loses only the clay-bound water; the capillary-bound water stays inside PHIE, and what flows is PHIFF = PHIT − CBW − CAPBW. It lives on the Advance tab beside SSC.

Sandstone units are a requirement of the spec

The specification states NPHI must be in sandstone units — so pin the NPHI input to NPHI_SS (from Neutron Matrix Conversion), exactly as the SSC chapter does.

Enter the spec parameters and the shale point

All entered values and their origins, as recorded in the run's reference field:

  • NPHI_MAT 0 · RHOB_DSH 2.71 · VOL_CBW_SH 0.1 · SWIRR_MIN 0 — the values the SSPW specification itself records.
  • RHOB_SH 2.45 / NPHI_SH 0.42 (sandstone units) — medians of SANDI-01's samples at GR ≥ 112 gAPI: this dataset's own shale point, preferred over the spec's example values because it is measurable here.
  • GAS_C 1.6 — the shipped, cited default; SSPW corrects the density leg only, so the leg-crossing behaviour SSC shows above c = 1 has no counterpart here.

Run and read

On these wells: 3 clean. Outputs: PHIT/PHIE/PHIFF_SSPW, the three bound-water volumes (clay-bound, capillary-bound, total) and SWIRR_SSPW. Put PHIT, PHIE and PHIFF_SSPW on one track: the gap between PHIT and PHIE is the clay-bound water, and the gap between PHIE and PHIFF is the capillary-bound water the method exists to separate.

Three-component sandstone workflow (quartz + shale + water). PHIT from density with a VSH-mixed dry matrix (RHOB_MAT / RHOB_DSH); shale total porosity PHIT_SH = (RHOB_DSH − RHOB_SH)/(RHOB_DSH − RHOB_FL); CBW = VSH·VOL_CBW_SH; CAPBW = VSH·(PHIT_SH − VOL_CBW_SH). Key message: PHIE = PHIT − CBW (clay bound only); PHIFF = PHIT − CBW − CAPBW is the movable-fluid porosity; SWIRR = (CBW+CAPBW)/PHIT floored at SWIRR_MIN. NPHI must be sandstone units. Exec arithmetic reconstructed from the reference spec — check against the reference PHIT/PHIE LAS output.
