Multimin — Mineral Inversion (retired · use SandiMin)

Module id multimin · category Saturation

This module is retired — use SandiMin

Multimin was the original fixed four-component mineral solver (sand, clay, water, hydrocarbon from RHOB/NPHI/DT/PEF). It has been superseded by SandiMin (Advance ▸ Mineral Solver), a general component-library solver with editable endpoints, zoned fluids and the full constraint set. Running a multimin step now returns a message directing you to SandiMin instead of executing.

Why the entry still exists

Saved workflow chains reference their steps by module id. Deleting the manifest would break every chain saved before the retirement — the step would vanish from the chain editor along with its stored parameters. So the manifest is kept, the runner refuses, and this page exists to say where the capability went.

If you have an old chain with a multimin step

  • The step still shows its stored parameters in the chain editor — nothing saved is lost.
  • Rebuild the step with SandiMin: pick the equivalent components (a quartz mineral, a clay, water and hydrocarbon fluids) and the same input logs. The old solver's outputs (VOL_*, PHIT_MM, VSH_MM, SWT_MM, RECON_ERR) map to SandiMin's VOL_<component> and SM_-prefixed result curves.
  • Projects that already carry MM_* curves keep them — a re-run writes new SM_* curves beside them rather than overwriting history.
