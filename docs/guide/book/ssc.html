SSC — Sand-Silt-Clay (Kuttan/LQR)

Module id ssc · category Porosity

Sand-Silt-Clay model on the neutron-density crossplot: gas-conditions the (RHOB, NPHI) pair, projects it onto the dry line of a six-point framework, splits the rock into sand, silt and clay fractions, and carries the split through porosity, bound-water and irreducible-saturation arithmetic.

Gas conditioning (Δ = |PHIDI² − NPHI²|, c = GAS_C):
PHID = √(PHIDI² − c·Δ/2),  NPHI_COR = √(NPHI² + c·Δ/2)
PHIT = (RHOMA − RHOB_COR)/(RHOMA − RHOB_FL),  RHOMA = Σ fraction·ρ over sand/silt/clay
PHIE = PHIT − VWCL·PHIT_CL,  PHIFF = PHIT − CBW − CWSH
SWIRR_T = BW/PHIT,  SWIRR_EFF = 1 − PHIT·(1 − SWIRR_T)/PHIE

References

  • Kuttan et al., Log Interpretation in the Malay Basin, 21st SPWLA Annual Logging Symposium

The LQR/GAP-2023 modification and the two tight-rock conditioning rules are the interpreter's own additions to the published model.

Step by step: the Sand-Silt-Clay split

SSC is one of this application's flagship methods — the Kuttan Malay Basin model with the interpreter's own LQR/GAP-2023 modification, splitting the rock into sand, silt and clay on the neutron-density crossplot and carrying the split all the way to bound water and irreducible saturation. It lives on the Advance tab, not in the Petrophysics dropdowns.

Prepare the inputs

  • NPHI in sandstone units — the six-point framework is written with the matrix at NPHI 0, so pin the NPHI input to NPHI_SS (from Neutron Matrix Conversion).
  • GR — the input prefers GRN, the normalized gamma ray, because the method was built to run on field-normalized GR. This project carries no GRN, so the input is pinned to the raw GR and the endpoints below are picks from that raw curve. On a multi-field project, normalize first and let the default resolution find GRN.

Enter the framework

Every framework point ships without a default — the six-point triangle is a basin statement, not software's to guess. This run entered the reference Loglan values from the method's own note, plus the data picks, all recorded in the reference field:

  • Wet clay (2.3, 0.6) · dry clay 2.71 · wet silt NPHI 0.3 · DCLF_SI 0.1 — the reference Loglan's values.
  • GR_MA 44 / GR_SH 112 — the first-hour picks from this dataset's raw GR.
  • NPHI_MA 0 — the sandstone matrix point, consistent with NPHI_SS.
  • PHIT_CL 0.24 — the wet-clay porosity implied by the entered clay points: (RHOB_DCL − RHOB_WCL)/(RHOB_DCL − RHOB_FL) = (2.71 − 2.3)/(2.71 − 1). Stated as arithmetic in the reference field so the number's origin travels with the run.
  • SWIRR_MIN 0 — the reference value; the SWIRR conditioning rule stays off unless a zone sets it.

Run and read

On these wells: 3 clean. The outputs are the whole story of the method: the sand/silt/clay volumes (and their GR-rescaled twins), PHIT and PHIE, the clay-bound and capillary-bound water split (CBW, CWSH), and the irreducible saturations. CWSH is what the RtC saturation method consumes as its CAPBW input — this module is the front half of the LRLC workflow.

What the application enforces

Everything below is generated from the same manifest the application builds this module’s pane from — descriptions, defaults, sources, ranges and pre-run checks here are exactly what the running application enforces.

Sand-Silt-Clay model on the N-D crossplot (Kuttan Malay Basin, GAP 2023 LQR edit). Data points are projected from the fluid point onto the dry rock line (matrix→dry clay); sand/silt/clay fractions come from the projection position, matrix density from the fraction mix, PHIT from density. Bound water is split into clay-bound (CBW) and capillary-bound in silt/shale (CWSH): PHIE = PHIT − VWCL·PHIT_CL, PHIFF = PHIT − CBW − CWSH, SWIRR_T = BW/PHIT. GR-equivalent volumes rescale the SSC volumes to honour VSHGR. Study-specific crossplot endpoints ship absent and must be supplied from the active interpretation.
