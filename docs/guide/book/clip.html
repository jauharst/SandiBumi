Step by step: holding a curve inside a range

Clip holds a curve inside a declared range, with two very different actions. BLANK (the default) turns an out-of-range sample MISSING: the right answer when the range is a validity check, because a resistivity of 10⁶ is not a very resistive rock, it is a reading the tool could not make, and pinning it to the bound would leave a real-looking number where there is no measurement. CLAMP pulls the sample to the bound, defensible only for a small arithmetic overshoot of a known physical limit. An empty bound is a statement that the curve is unbounded on that side, not an omission.

Two runs, two lessons

At the physical bound [0, 120] gAPI this delivery blanked nothing. Pooled GR tops out at 115.6, and a validity screen that finds nothing to do says 3 clean and changes nothing, which is itself the answer.

So the shipping run is an explicitly labelled machinery demonstration: [0, 110], a bound deliberately below the pooled P97 of 112, chosen to blank the top shale readings so the Fill Gaps chapter has real gaps to work with. The run's reference field says exactly that; on a real study you never blank legitimate readings.

Run and read

On these wells: 3 clean, with 184 samples blanked into GR_CLP, the shale peaks above 110. The out-of-range flag marks each one and GR_CLP_ORIG keeps every original value, so even a demonstration is fully reversible.

Holds a curve inside a range. MIN and MAX are in the curve's own units and either may be left EMPTY, which is a statement that the curve is unbounded on that side rather than an omission. ACTION: • BLANK — a sample outside the range becomes MISSING. The right answer when the range is a validity check: a resistivity of 1e6 is not a very resistive rock, it is a reading the tool could not make, and pinning it to the bound would leave a real number where there is no measurement. • CLAMP — a sample outside the range is pulled to the bound. Only defensible when the excursion is a small arithmetic overshoot of a known physical limit, the way PHIE is floored at 0.001 rather than blanked. BLANK is the default because it is the one that cannot manufacture a measurement.
