Step by step: soft facies, with a confidence per sample

The Gaussian-mixture variant of electrofacies: every sample gets a membership probability per class instead of a hard assignment. FPROB is the winning class's posterior — 1.0 is unambiguous, about 1/K is a boundary or mixed sample — so transitional beds are visible instead of being forced into a class. Initialized from k-means, labels ordered by the first curve's mean, deterministic for a given seed.

The picks

Same curves and seed as the k-means run, so the two classifications are directly comparable — which is the QC this chapter demonstrates.

Run and read

On these wells: 3 clean — and an instructive pair of numbers. The two classifiers agree on 1122 of 1164 samples (96%), yet FPROB is essentially 1.0 everywhere (not one sample below 0.8). Generated data separates this cleanly; the 42 disagreements are boundary samples where the mixture's ellipsoidal classes draw the line differently from k-means' spherical ones — each model certain of its own answer. On real rock, expect the opposite signature: FPROB sagging toward 1/K exactly where facies interfinger, which is the map of where the hard classification should not be trusted.

Soft electrofacies: a Gaussian mixture model (diagonal covariance, EM, initialized from k-means) clusters this well's samples in the space of the supplied curves. Unlike k-means, every sample gets a membership PROBABILITY per facies — FPROB is the winning facies' posterior (1.0 = unambiguous, ~1/K = boundary/mixed sample), so transitional beds are visible instead of being forced into a class. Labels are ordered by the mean of the first supplied curve (usually GR). Deterministic for a given seed. Outputs: FACIES_GMM (integer 0..K-1), FPROB (max posterior, 0-1).
