This module is superseded: use Condition ▸ Normalize

GR Normalization was the original two-point percentile normalizer, fixed to the gamma-ray log. It has been folded into the general Normalize module (Petrophysics ▸ Condition), which does the same TWO_POINT percentile map on any curve, plus the RANGE and MEAN_SD methods and log-space mapping. The arithmetic is identical: the well's own P_LOW/P_HIGH percentiles mapped linearly onto a reference pair you supply.

What still resolves

gr_normalize stays in the catalog so saved workflow chains that reference it keep resolving and running; it delegates to the same code. It is only kept out of the pickers, so the same operation is not offered twice.

The one rule it carried, unchanged

The reference pair ships absent on purpose, and Normalize enforces the same refusal: a pair from one basin is the wrong reference in another, and normalized output looks plausible either way. Derive the pair from the field's own multi-well GR distribution and use the same pair for every well. The Normalize chapter walks through exactly that, including the refusal and the derived pair for these wells.
