Step by step: Coates, and which C you are actually holding

The Coates free-fluid form: porosity squared times the free-to-bound water ratio, squared again. Two things the pane's documentation pins down before you type anything: this is the Coates & Denoo 1981 producibility form, not the heavier Coates & Dumanoir 1974 model — and the constant C is scale-dependent, so published values are not interchangeable: 100 in this fractional form is the same rock as 10 in the percent-porosity NMR form, and Schlumberger's K-4 chart states 70. A quoted C without its convention is a trap.

The picks

  • CONST_COATES 70 — the Schlumberger K-4 chart value, exactly as the module's own documentation records it for this fractional form.
  • SWE_IRR 0.16 — the SSC-derived irreducible pick, consistent across the whole walkthrough.
  • PHIE pinned to PHIE_DEN.

Run and read

On these wells: 3 clean, median 65 mD in the sands — close to Wyllie-Rose's 73, an order of magnitude above the core-calibrated 2.8. The three-way spread across this shelf is the honest summary of log-derived permeability: the model chooses the answer, so the model must be named, calibrated where core allows, and cross-checked where it does not.
