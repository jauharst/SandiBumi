Step by step: reservoir-condition inputs in one pass

Pre-Calculation writes the curves the saturation and SandiMin work will keep asking for: formation temperature (always in °C, whatever unit you entered the trend in, plus FTEMP_F for SandiMin's fluid-property entry), formation pressure, mud-filtrate resistivity Arps-converted to formation temperature, and the QC conductivities CT and CXO.

The picks, each with its defence

  • OPT_TU degC, 26.7 + 0.0474 °C/m, the metric restatement of the shipped feet-based trend (and exactly ftemp_grad's metric starting values). The shipped 77 °F / 0.026 °F/ft pair is feet-based; entering it unconverted on a metric well is the recorded 66 °C mistake.
  • PSURF 14.7 + PGRAD 1.42 psi/m, atmospheric surface pressure plus the freshwater hydrostatic gradient (0.433 psi/ft restated per metre). A physical constant as a starting point, not a field fit; a measured pressure gradient replaces it the moment you have one.
  • ARPS, Rmf 0.2 ohmm at 25 °C: the module's own worked example, standing in for the mud report this synthetic delivery does not have.

Run and read: degraded is a statement, not a failure

On these wells: 0 clean · 3 degraded. And the degradation is the module being precise about what it could not do. This delivery carries no RXO curve, so CXO has zero finite samples (1185 rows, all missing) while FTEMP, FPRESS, RMF_FT and CT are complete. A missing input degrades exactly the outputs that need it and says so per well in Processing → details; it never fails the run or invents a flushed-zone conductivity.
