SandiBumi capability prerequisites

Native core, project open, plotting and native exports do not require Python.
Optional capabilities use one session-resolved Python 3.10+ subprocess:

Python equations: requires numpy; optional scipy.
DLIS import: requires dlisio, numpy.
Spreadsheet plate extraction: requires openpyxl, Pillow.
Workbook export: requires xlsxwriter.
Document export: requires python-docx.
Deck export: requires python-pptx, matplotlib.
ML models: requires numpy, scikit-learn, joblib; optional xgboost.
Core photo imaging: requires numpy, Pillow.
Petrography pore area: requires numpy, Pillow; optional scipy.
Mineral classifier: requires numpy, Pillow, scipy, scikit-learn.
Picture normalization: requires Pillow.

Offline deployment uses the separately signed, versioned SandiBumi-qualified Python pack, silently
deployed per machine by IT. It configures SANDIBUMI_PYTHON to its application-local interpreter.
Qualification blocks public network access and accepts zero observed requests. Exact package
versions come only from the qualified release lock.
